# ERØWAVE for iPhone

Native iOS 17+ music discovery and playback. The SwiftUI interface is in English. Bundle ID `com.eromchik.erowave`. The project includes a shared scheme, one app target, unit tests and UI tests. No dependencies, accounts, developer tokens or backend are required for the enabled catalogs.

## Сборка с Windows 11

1. Распакуй архив. В корне репозитория должны лежать `EROWAVE.xcodeproj`, `App`, `Tests`, `UITests`, `Info.plist` и `.github`. При использовании веб-интерфейса GitHub проверь, что скрытая папка workflow действительно попала в репозиторий.
2. Из папки проекта открой PowerShell. Для нового пустого репозитория выполни команды ниже. Вместо OWNER/REPO укажи свой адрес. Для существующего репозитория скопируй файлы в его рабочую копию и сделай обычный commit/push.

   ```powershell
   git init -b main
   git add .
   git commit -m "Add EROWAVE iPhone app"
   git remote add origin https://github.com/OWNER/REPO.git
   git push -u origin main
   ```

3. Открой **Actions → Build ERØWAVE for iPhone**. Push запускает сборку автоматически. Для повторного запуска открой **Run workflow** на основной ветке. Workflow выбирает установленный Xcode 16+ с доступным iPhone Simulator, запускает unit/UI tests, затем архивирует Release для `generic/platform=iOS`.
4. После успешной сборки скачай **Artifacts → EROWAVE-unsigned** и распакуй скачанный ZIP. Внутри будет `EROWAVE-unsigned.ipa`. При ошибке скачай **build-logs**, включая `Tests.xcresult`, если симулятор успел его создать.
5. Для установки нужна действительная подпись и подходящий provisioning profile для устройства и bundle ID. Сам файл из Actions собирается с `CODE_SIGNING_ALLOWED=NO`.

На Mac открой `EROWAVE.xcodeproj` в Xcode 16 или новее. Выбери схему **EROWAVE**, iPhone Simulator и нажми Run. Для физического iPhone выбери команду разработчика в Signing & Capabilities, устройство и Run.

## Что можно попробовать сразу

- Пропусти onboarding. **Home → After Hours → Play** запускает три оригинальных стереозаписи по очереди. Музыка и обложки находятся в приложении.
- Нажми стрелку вниз или потяни обложку вниз. Перейди в Library, разверни мини-плеер и открой Queue.
- **Library → Offline Music → Import from Files** импортирует поддерживаемый незашифрованный аудиофайл. Приложение копирует его в Application Support, читает встроенные название, артиста, альбом и длительность.
- **Discover** отправляет запрос по пяти каталогам. Результаты появляются по мере ответов. У внешних записей есть пометка **Open externally**. У доступных для плеера записей стоит **Full track**.
- Меню трека позволяет поставить лайк, создать плейлист, добавить в очередь, поделиться ссылкой или перейти к доступным сведениям. В плейлисте кнопка Edit позволяет менять порядок и удалять записи.
- **Player → Lyrics → Import LRC** открывает локальный файл с таймингами, на использование которого у тебя есть права. Выключи Follow playback для ручной прокрутки. Нажатие на строку перематывает запись. Для инструменталов предусмотрено отдельное состояние.
- В профиле можно изменить имя, проверить историю, включить воспроизведение сетевого аудио только по Wi-Fi и очистить историю или кэш запросов.

## Каталоги

| Источник | Операции в этой версии | Воспроизведение и ограничения |
| --- | --- | --- |
| Audius | Поиск треков, недельный чарт, арт, сведения об артисте и ссылки. | Официальный stream endpoint для явно доступных незакрытых записей. Сервер повторно определяет доступ при открытии потока. Gated-записи открываются в Audius. Аудио не скачивается. |
| iTunes Search / Lookup | Поиск до 25 треков, официальные ссылки, lookup по ID альбома/артиста с учётом страны. | Только метаданные. Promo audio и изображения исключены из плеера, очереди и карточек. |
| MusicBrainz | Записи, исполнители, сведения о релизах и ISRC при наличии, страницы записей, постраничный поиск. | Только метаданные. Клиент ограничивает частоту запросов. Для коммерческого использования публичного веб-сервиса нужно отдельно оформить условия с MetaBrainz. |
| Internet Archive | Поиск аудиообъектов по названию и автору, пагинация, страницы объектов. | Одна запись каталога может содержать целый концерт. Открывается оригинальная страница с её условиями. |
| Library of Congress | Поиск по цифровым аудиоколлекциям, авторы и даты при наличии, пагинация, страницы объектов. | Ссылки на первоисточник. Лимит клиента ниже 20 запросов в минуту для этого хоста. |
| ERØWAVE Studio и личные файлы | Встроенный EP, локальные плейлисты, история и импорт. | Полные локальные записи работают без сети. Поиск по Studio встроен в Discover. Импортированные записи находятся в Offline Music. |

## Устройство проекта

| Модуль | Ответственность |
| --- | --- |
| App/App | Контейнер SwiftData, один PlayerStore на всё приложение, сохранение позиции при смене scenePhase. |
| App/Core | Codable-модель записи, проверка возможности воспроизведения, независимые каталоги, агрегация и SearchStore. |
| App/Networking, App/Providers | URLSession, дедлайны, задержки для каждого хоста, обработка 429/5xx, ограниченные повторы, провайдер-специфичные DTO. |
| App/Audio | AVPlayer, очередь, повторы, shuffle, восстановление в паузе, фон, AirPlay, прерывания, отключение наушников, команды с экрана блокировки. |
| App/Persistence | SwiftData, избранное, история событий, недавно прослушанные, плейлисты и сохранённые сущности. Перенос старого UserDefaults-избранного. |
| App/Features, App/DesignSystem | Навигация, OLED-компоненты, matched artwork, плавный фон из обложки, ограниченные областью экрана анимации, Reduce Motion, системные VoiceOver-метки. |
| App/Resources | Три оригинальные AAC-композиции и их обложки, иконка. В записи не включены сторонние сэмплы. |

Поиск использует debounce 300 мс и отмену предыдущей задачи. Кэш результатов находится в памяти и ограничен 40 страницами и 90 секундами. Нормализация, текстовое сходство и точные совпадения влияют на ранжирование. Объединяются одинаковые ID или совпадения ISRC, нормализованных артиста и названия с версией и длительности, округлённой до секунды. Это консервативное правило может оставить дубликаты. Плейлисты в Discover относятся к локальной библиотеке. Вкладки Artists и Albums отдельно запрашивают каталоги iTunes и MusicBrainz, а Genres группирует жанры найденных записей. Для результатов поиска сущностей открывается отдельная карточка с lookup/browse по ID.

Персональные подборки появляются при наличии локальных лайков и истории. Daily Mix меняет стартовую позицию по дню. Chart, артисты и жанры опираются на ответ Audius. Список релизов ограничен датированными записями из чарта за последние 30 дней.

## Проверки и готовность

В среде подготовки проверены целостность ZIP, пути и ссылки Xcode-проекта, plist, общая схема и структура workflow. Три встроенные аудиодорожки целиком декодированы FFmpeg. Здесь отсутствуют Swift compiler, Xcode и iOS SDK. Компиляция приложения, XCTest, UI-тесты, стабильность сетевых потоков на устройстве, визуальная проверка и замер кадровой частоты пока не подтверждены. Готового IPA в исходном архиве нет.

В targets Tests и UITests включены сценарии агрегации, отказа и отмены, объединения версий, очереди и восстановления, SwiftData на диске, legacy-превью, gated media, ресурсов, LRC, навигации и открытия плеера. Для проверки на iPhone после сборки сверь перемотку с фактическим звуком, смену маршрута AirPlay/Bluetooth, звонок, блокировку дисплея, новый запуск после закрытия и поведение в авиарежиме.

## Границы текущей версии

- MusicKit, Spotify, Deezer, SoundCloud, Jamendo и YouTube не подключены. Для будущих интеграций нужны подходящий режим доступа, права, а для части сервисов — отдельная серверная авторизация. У активных адаптеров нет серверных секретов, поэтому FastAPI и файл окружения не требуются.
- Нет коммерческого каталога лицензированных текстов, загрузки сетевой музыки, облачного аккаунта, синхронизации между устройствами, push и отдельной Live Activity. Системный Now Playing обслуживает системные медиаконтролы.
- Профили артистов показывают подтверждённые сведения, когда они пришли из провайдера. Полнота дискографии, related artists и поиск всех типов сущностей отдельными endpoint не обеспечиваются. Альбомы без полного lookup помечены как доступные записи. Чарт отражает Audius, а не весь музыкальный рынок.
- Качество сетевого потока определяет провайдер. Переключателя качества, который не меняет поток, в интерфейсе нет.
- Перед коммерческим запуском требуется проверка условий каждого включённого провайдера для конкретной бизнес-модели, нагрузки и территорий. Исходники не включают договоры на распространение сторонних каталогов.
